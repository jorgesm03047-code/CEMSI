# CEMSI · Historia clínica

Formulario independiente para pacientes, en español e inglés. Mantiene la identidad visual de CEMSI. Es una web estática sin dependencias ni proceso de compilación.

## Cloudflare Pages con GitHub

- Repositorio: `jorgesm03047-code/CEMSI`
- Rama de producción: `main`
- Directorio raíz: `historia-clinica`
- Framework: ninguno
- Comando de compilación: vacío
- Directorio de salida: `.`

El proyecto de Pages debe ser independiente de la página principal. Cada cambio en esta carpeta se publica desde GitHub. No se necesitan secretos ni variables de entorno.

## Datos y uso

`?lang=en` abre en inglés. Las respuestas permanecen en memoria; solo se guardan localmente cuando el paciente activa el borrador, con caducidad de siete días desde su último cambio. Puede borrar respuestas, descargar texto o imprimir/guardar PDF. La firma manuscrita se completa en consulta. No hay envío automático de respuestas, analítica ni expediente remoto.

La sección reservada al profesional no forma parte de este formulario para pacientes. No se incluyen los datos del paciente del documento de referencia. Los consentimientos permanecen sin marcar por defecto y se pueden aclarar en consulta.
